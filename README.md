Digital Dependency Score Prediction Using Linear Regression to Determine Brain Rotting:

Project Overview:

This project predicts the Digital Dependence Score using a Linear Regression machine learning model. The model was trained on the Digital Lifestyle Benchmark Dataset to analyse how digital lifestyle habits affect a person's level of digital dependence. A Streamlit web application was also developed to allow users to enter their information and receive an instant prediction.

 

Dataset: Digital Lifestyle Benchmark Dataset

 Features:
- Age
- Gender
- Region
- Daily Screen Time (hours)
- Daily Phone Unlocks
- Daily Notifications
- Sleep Duration (hours)
- Sleep Quality (0–5)
- Stress Level (1–10)
- Focus Level (0–100)
- Productivity Score (0–100)

 Target Variable:
- Digital Dependence Score

Technologies Used:

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit
- Pickle
- Joblib

 Machine Learning Model:

Both Linear Regression and Polynomial Regression were implemented and compared during the development process. After evaluating their performance, Linear Regression was selected as the final model because it achieved the best overall results while remaining simple, interpretable, and efficient for predicting the Digital Dependence Score.

 Data Preprocessing:

- Checked for missing values
- Handled missing or inconsistent data
- Encoded categorical variables
- Selected relevant features
- Split the dataset into training, validation, and testing sets
- Scaled numerical features where necessary

The dataset was analysed by:

 Model Evaluation

- Mean Squared Error (MSE): 0.0022
- R² Score:1.00

The model achieved a very low Mean Squared Error and an R² score of 1.00, indicating excellent predictive performance on the evaluated data.

Streamlit Application:

A Streamlit application was developed to provide an interactive interface for predicting the Digital Dependence Score. Users can enter their digital lifestyle information and receive an instant prediction generated by the trained Linear Regression model.
